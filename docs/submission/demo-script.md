# Qling 出海智察｜3 分钟初赛演示脚本

## 0:00–0:25 问题

“跨境小团队做一个 USB-C 充电器选品，要同时翻评论、比价格、查法规。真正困难的不是信息少，而是结论无法回到证据，AI 摘要也可能编造来源。Qling 出海智察把这些资料变成可追溯的进入决策。”

画面：首屏、目标市场、FIXTURE 原型标识。明确说明当前演示数据不会上传。

## 0:25–0:55 数据进入与安全

点击“下载 CSV 模板”，展示列结构；随后导入 `reviews-template.csv`。

“我们只接受业务必要字段。邮箱、电话、地址和订单号等个人信息列会被直接拒绝。系统不实时爬取平台，也不在浏览器保存模型密钥。”

## 0:55–1:35 三项核心能力

依次指出：

1. 评论痛点识别出“高负载发热”和“多口切换中断”。
2. 每条结论附原始片段、日期和来源；本地演示证据被明确标记。
3. 机会指数由固定权重计算，模型不能直接改变最终分数。
4. FCC 提醒指向权威页面，并标注需人工复核、不构成法律意见。

## 1:35–2:15 决策辅助

滚动到竞品快照，说明价格与评分中位数对应同一采集时间，不声称实时行情。

将售价从 `$39.99` 调整为 `$49.99`：

“在到岸成本、平台费、广告费和启动成本假设下，系统即时计算单件贡献与保本销量。这是透明的情景计算，不是销量预测。”

## 2:15–2:40 可审计输出

点击“导出证据报告”。

“导出的 JSON 同时包含分析结论、竞品快照、定价假设、来源和免责声明，便于团队复核或进入下一轮调研。”

## 2:40–3:00 差异与路线

“与通用聊天机器人不同，我们的模型只能引用导入数据里存在的记录 ID，虚构引用会被合同层拒绝。当前 Web 和 Electron 离线版本已跑通；下一步是扩充 200 例人工黄金集、完成百炼真实联调和用户验证。”

## 演示失败回退

- 网络不可用：直接使用 Electron 离线版和 fixture 数据。
- CSV 文件选择失败：刷新页面，内置样例仍展示完整三项核心能力。
- 外部法规链接不可访问：展示导出 JSON 中已保存的摘要、日期与 URL，不声称实时核验。
- 定价输入无正贡献：界面会提示调整参数，不会崩溃。
