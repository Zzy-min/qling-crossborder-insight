# Qling 出海智察｜3 分钟复赛演示脚本

> 复赛增量：初赛以 fixture provider 演示，复赛已完成真实百炼联调（9/9 冒烟 + 12/12 模型合同评测）。

## 0:00–0:20 问题与定位

"跨境小团队做选品，要翻评论、比价格、查法规。真正难的不是信息少，而是结论无法回到证据——AI 摘要可能编造来源。Qling 出海智察把数据变成可追溯的进入决策。"

画面：首屏 01 数据准备页，目标市场切换器，FIXTURE 原型标识。

## 0:20–0:45 数据与安全

点击"下载 CSV 模板"展示列结构，导入 `reviews-template.csv`。

"只接受业务必要字段，邮箱电话地址直接拒绝。不实时爬取平台，不在浏览器保存密钥。"

## 0:45–1:40 真实百炼联调（复赛核心增量）

切换到真实模式：

1. 工具栏显示"百炼可用" → 点击"运行百炼增强"
2. 进度面板显示"真实模型推理中 · 通常需 10–60 秒"
3. 等待真实响应到达（约 5–9 秒）后自动进入 02 市场机会页

"初赛时这里用的是本地规则，现在走的是阿里云百炼 qwen3.7-plus 真实模型。模型只能引用数据集里存在的记录 ID——编造的引用会被合同层直接拒绝。12 例模型合同评测：零幻觉，37 个主题全部有评论关键词接地。"

依次指出 02 页核心：
- 机会指数由固定权重计算，模型不能直接改分
- 评论痛点每条附原始片段和来源
- 美国 FCC 与欧盟共同充电器分别指向官方页面，标注需人工复核

## 1:40–2:15 定价情景与竞品

滚动到竞品快照，说明价格中位数对应同一采集时间，不声称实时行情。

将售价从 $39.99 调为 $49.99：

"系统即时计算单件贡献与保本销量。这是透明的情景计算，不是销量预测。"

## 2:15–2:40 可审计输出

点击"导出证据报告"。

"导出的 JSON 包含分析结论、竞品快照、定价假设、来源和免责声明，便于团队复核。"

## 2:40–3:00 失败回退与差异

"如果网络不可用或百炼超时，界面会安全回退到本地确定性报告，并提供重试入口。与通用聊天机器人不同，每条结论都有 recordId 可追溯——这就是初赛到复赛的增量：从离线原型到真实 AI 链路，合同不变。"

## 演示失败回退

- 百炼不可用：点击"运行百炼增强"后显示回退提示 + 重试按钮，使用 fixture 数据继续演示。
- CSV 文件选择失败：刷新页面，内置样例仍展示完整核心能力。
- 定价输入无正贡献：界面提示调整参数，不会崩溃。

## 录制注意事项

- 录制前确认 `npm run dev:api` 已启动且 `.env` 配置了真实 `BAILIAN_API_KEY`
- 先跑一次 `npm run smoke:real` 确认链路通畅
- 真实模型调用约 5–9 秒，进度面板会自动显示阶段轮播，不要手动跳页
- 录制环境：本地启动，不依赖外部部署
