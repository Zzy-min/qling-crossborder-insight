# Qling 出海智察｜初赛创意方案唯一事实源

> 状态：草稿，尚未提交 CSDN。外部提交前必须逐字段核对并再次获得最终确认。

## 基本信息

- 团队名称：轻灵
- 参赛赛道：AI 市场洞察
- 项目名称：Qling 出海智察
- 目标品类：美国、欧盟市场的 USB-C 充电器

## 一句话介绍

将公开、可追溯的商品评论和监管资料转化为带证据的用户痛点、机会评分与合规预警，帮助小团队更稳妥地做跨境选品决策。

## 痛点与目标用户

跨境新品决策通常依赖分散的评论、竞品价格和法规页面。个人卖家与小团队缺少专职研究员，容易漏掉高频体验问题，或把法规摘要误当成确定法律结论。产品面向准备进入美国、欧盟市场的中国跨境卖家、产品经理和独立开发者。

## 方案说明

用户导入依法获得的商品与评论 CSV，系统首先执行字段校验、隐私列拦截和去重，再围绕评论痛点、竞品空间、数据置信度与合规成本生成机会评分。每个主题和风险都绑定原始记录、时间与来源链接，支持人工回查。演示样例聚焦 USB-C 充电器，识别高负载发热、多口切换中断等问题，并基于 FCC 等权威页面给出需人工复核的合规提醒。系统不进行实时抓取，也不把模型输出表述为法律意见。

## 创新点

1. 不是只给摘要，而是输出“结论—证据—时间—来源”的可审计链路。
2. 将评论痛点、改善空间、竞争与毛利、数据置信度、合规惩罚纳入同一可解释评分。
3. 模型只能引用导入数据中的记录 ID；虚构引用会被合同层拒绝。
4. Web 主演示与离线样例并行设计，弱网现场仍可复现核心流程。

## 当前完成度

- 已完成：CSV 导入校验、隐私字段拒绝、评论主题、机会评分、合规证据、竞品快照、定价情景、JSON 证据报告导出、Web 报告薄切片、Provider 合同、起步黄金集门禁和 Electron 离线备份。
- 尚未完成：真实百炼联调、200 例人工复核黄金集、用户访谈执行、公开体验地址与复赛视频。

## 技术方案

- 前端：React + TypeScript + Vite
- 领域内核：确定性评分与证据绑定
- 模型层：fixture / mock / 百炼兼容接口；密钥只允许由服务端注入
- 质量门禁：Vitest、TypeScript 构建、黄金集召回率、证据覆盖率与未知引用计数

## 初赛演示路径

导入样例 CSV → 查看数据校验 → 生成痛点主题 → 查看机会评分拆解 → 展开合规预警及原始证据 → 导出/展示决策建议。

## 数据与安全边界

仅使用公开可追溯样例和用户依法导出的 CSV；拒绝 email、phone、address 等个人信息列；不实时爬取平台数据；不在前端或仓库保存 API Key；合规输出必须标注人工复核。
