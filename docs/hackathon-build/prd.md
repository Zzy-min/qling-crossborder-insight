# Qling 出海智察 PRD

## 目标

为准备进入欧美市场的中小跨境卖家提供可追溯的 USB-C 充电器市场进入决策。产品把公开样例或用户合法导出的商品、评论和政策 CSV 转化为评论痛点、机会评分、合规预警与证据化建议。

## 初赛承诺

- 团队：轻灵
- 赛道：AI 市场洞察
- 产品：Qling 出海智察
- 三项主功能：评论洞察、机会评分、合规预警
- 两项辅助功能：竞品快照对比、定价情景模拟
- 核心 AI 能力最终经阿里云百炼 Model Router 调用；当前原型使用显式标注的 fixture provider
- 不做实时爬虫、账户系统、多用户协作或自动法律判断

## 成功标准

1. 无网络、无 API Key 时可从内置样例生成完整报告。
2. 同一输入产生完全一致的确定性评分。
3. 每条结论包含来源、日期和证据片段；无证据时不输出强结论。
4. CSV 错误能定位到行和字段。
5. Web 首屏 30 秒内能解释用户、问题、结论和依据。
